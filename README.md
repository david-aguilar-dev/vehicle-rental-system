# 🚗 Vehicle Rental Management System

An object-oriented Windows Forms desktop application developed in C# to manage vehicle rental reservations, fleet inventory, and dynamic pricing calculations.

## 📌 Project Overview
Designed to streamline rental operations for car rental agencies by validating customer inputs, managing vehicle availability status, and executing automated rate calculations based on rental duration and vehicle category.

## 🚀 Features
- 🔹 **Fleet Management:** Add, update, and organize vehicle categories and rental rates.
- 🔹 **Booking & Cost Calculation:** Automated rate algorithms factoring in rental days and selected add-ons.
- 🔹 **UI & Data Validation:** Form handling with strict user input validation to prevent invalid bookings.
- 🔹 **OOP Principles:** Modular architecture leveraging inheritance, encapsulation, and abstractions.

## 🛠️ Tech Stack
- **Language:** C# (.NET Framework)
- **UI Framework:** Windows Forms (WinForms)
- **IDE:** Visual Studio
